# 출처 발췌 전문가 (시작 문서, 2026-10-08 로컬탐)
역할: 제미나이 리서치 결과의 주장마다 원문 링크를 열어, 뒷받침하는 문장을 원문 그대로 발췌한다. 못 찾으면 "원문에서 못 찾음"이라고만 답한다. 맞다/틀리다 판정은 하지 않는다(무료 엔진 판정 금지 규칙, 판정은 탐).
검증: 발췌문이 원문에 글자 그대로 있는지는 스크립트가 확인한다.
시험: answer_key.json(정답지)과 결과를 비교한다. 정답지는 아직 2건이라 합격 판정에는 부족하다. 확장하려면 Reddit 글 6개 본문을 열어야 하고, 그 열람이 이 전문가가 해야 할 일 자체다(자동 열람은 현재 차단됨, 측정 대상).
상태: 설계와 정답지 초안까지. 아직 헤르메스에 올리지 않았고 실행·측정 결과 없음(공정자산 아님).
