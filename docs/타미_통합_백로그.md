## 3. 신뢰성과 안전
- **진행·미해결:** 완료한 의뢰의 원본이 대기 폴더에 남아 같은 의뢰를 반복 실행(이번 세션 3건). 지금은 탐이 직접 지움. 근본 처방: 타미가 done 이동 시 원본 삭제 또는 완료 표지, 반복 실행 감지 알림.
- **진행:** 윈도우 프로그램 호출 시 경로 형식 불일치(덱스 `/c/` 경로 실패는 `ask_dex.sh` 수정으로 병합, gcloud는 cmd.exe 경유로 재점검 중). 타미용 스크립트 템플릿에 "윈도우 프로그램은 C:/ 경로 또는 cmd.exe 경유" 규칙을 넣을 것.
- **대기:** 폴러 정지·실패 알림(퍼포먼스 #9, B11). 증거: 폴러를 일부러 멈췄을 때 5분 안에 알림.
- **대기:** 완료 보고 자동 검증, 증거 없는 DONE 0건(퍼포먼스 #10, B12). 이번 세션 교훈: 에이전트의 "완료" 말은 증거로 쓰지 않는다.
- **원칙(확립):** 공개 저장소에는 프로젝트 id, 계정, 응답 내용을 올리지 않는다. 필요하면 비공개 이슈 425 댓글로 우회.
