# 헤르메스 모델 로스터 (2026-09-19 사장님 확정)

한 줄 요약: 대장은 OpenRouter의 nemotron-ultra, 서브대장은 OpenRouter 밖 모델, 막내는 로컬 qwen. 제미나이는 폴백에서 빼고 딥리서치 검증 전용으로만 쓴다.

## 1. 현재 구성 (설정 파일로 확인)
| 자리 | 모델 | 경로 | 이유 |

| 대장 | nemotron-3-ultra-550b (무료) | OpenRouter | 성능 우선. 사장님 확정 |
| 서브대장 | Upstage solar-pro4 | Upstage 직접 API | OpenRouter와 한도가 별개(아래 2절). 시험 호출 HTTP 200 |

- 서브대장 자리는 OpenRouter 밖 모델이면 교체 가능하다. DeepSeek 직접 API는 키가 있으나 잔액이 없어(HTTP 402) 후보로만 둔다.
- 폴백 순서 변경 이력: 2026-09-19 오후, 설정 백업 `config.yaml.bak_0919_roster`.

## 2. 왜 이렇게 됐나 (실측 근거)
1. OpenRouter의 `:free` 모델은 **계정 전체가 하루 요청 한도를 공유**한다. 누적 $10 이상 구매하면 1,000회, 미만이면 50회(공식 문서, 계정 조회로도 확인: 오늘 1,000회 한도 적용, 873회 사용). 대장이 막히면 같은 OpenRouter 무료 모델은 함께 막히므로 폴백으로 의미가 없다.
2. 제미나이 `gemini-3.6-flash` 무료 한도는 **키(프로젝트) 하나당 하루 20회**(429 응답의 한도값). 폴백으로 쓰면 딥리서치 검증 한도를 먼저 소모한다. 그래서 검증 전용으로 분리했다.
3. Groq 키는 401(무효)이었고 무료 모델이 없어졌다는 사장님 확인으로 체인에서 뺐다.
4. OpenCode Zen의 무료 딥식은 키가 있어도 호출이 막힌다(400/403/500, 2026-09-19 시험). 채택하지 않았다.
5. 체감 속도(사장님): 제미나이 > 솔라 > 링 = 네모트론.

## 3. 제미나이 키 사용 규칙 (검증과 다이얼로그 전용)
- 사장님 지시(2026-09-19): 제미나이는 **① 딥리서치 검증 ② 심플리파이어 다이얼로그(마야용, `docs/질문하기_파이프라인.md`)** 두 곳에만 쓴다. 폴백에는 쓰지 않는다.
- 다이얼로그가 어느 키를 쓰는지, 하루 20회 한도와 부딪히는지는 **미확인**(질문하기 문서에 "제미나이 무료 티어 처리 용량이 걸리면 대기 티켓" 계획만 있음). 내일 확인한다.
- 키는 3개. `verify_claims.py`가 검증 전용 키 → 보조 키 → 기존 설정 키 순서로 시험해 한도가 남은 키를 고른다.
- API 실패는 판정이 아니라 `error`로 표시하고 종료 코드 2를 낸다(예전에는 "unsupported"로 섞여 보임).
- 압축·이미지 보조 모델은 `gemini-3.5-flash-lite`로 교체했다(2026-09-19, 사장님 승인). 3.6-flash 한도를 검증과 다이얼로그용으로 남기기 위함이다. 이미지 입력 시험 HTTP 200.
