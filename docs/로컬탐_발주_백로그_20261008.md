# 로컬탐 발주 백로그 v2 (2026-10-08, 탐 클라우드)

역할: 로컬탐은 **로컬에서만 되는 일**만 하고 지휘(발주, 5줄 요약, 1줄 판정)에 쓴다. 이번 주 로컬 한도가 90% 찼다. 나머지는 클라우드 탐(클라우드 크레딧), 타미(무료), 제미나이·Vertex(GCP 크레딧)가 한다.

## 지휘 규칙 (로컬 크레딧 최소)
- 본체 도구 호출은 세션당 30회 이내. 파일은 `grep`·`head`·줄 범위로만 읽는다. 결과 보고는 5줄.
- 엔진 순서: 스크립트 → 타미 → 로컬 LLM → 덱스·비티(검증). 소넷 서브에이전트는 쓰지 않는다.
- 폴링 금지. 결과는 `notify/`와 `mailbox/탐/` 푸시로 클라우드 탐에게 간다.
- 컨텍스트 40%를 넘으면 중단하고 인수인계를 남긴다.
- 교신 규약(`hansunghee7.github.io/docs/에이전트_교신_규약.md`)을 따른다. 상대 에이전트(클로이 포함)나 대표님께 보내는 메시지는 사람 발신 승인 없이 보내지 않는다. 이 백로그에는 외부 발송이 없다.
- 쓰기 거부가 나면 우회하지 말고 보고한다. 비밀값은 출력하지 않는다.

## 로컬탐의 일 (로컬에서만 되는 것)
- **L1 신PC 클론 복구** · 엔진 스크립트. `git -C C:/work/solar-bible pull --ff-only` 후 `bash C:/work/solar-bible/tasks/assets/repair_poller_clone.sh`. 성공 증거는 `notify/repair-poller-clone-done.md` 푸시. 이 일이 끝나야 타미가 정상 동작한다.
- **L2 숙제 초안 3종의 로컬 부분** · 엔진 로컬 LLM(Qwen)·타미로 초안, `ask_dex.sh`·`ask_bt.sh`로 덱스·비티 검증(둘 다 로컬에서만 호출된다). 재료는 비공개 simplifier-cxo-db 이슈 #425(대표님 회신 요약). ① 월요일 환경 확인 체크리스트(브랜치 보호, 키 분리, 읽기 전용 토큰, 보안 조언) ② AI에 넣어도 되는 데이터 규칙 1장 ③ 에이전트·지침·저장소 한 장 목록 v0(Notion 허락 전이라 모르는 칸은 "확인 필요"). 초안·검증 결과는 `reports/`에 올리고 로컬탐은 각 5줄 요약과 1줄 판정만 `mailbox/탐/`에 남긴다. 최종 정리는 클라우드 탐이 한다. 외부 발송은 하지 않는다.
- **L3 (선택) 크롬 로그인 확인** · 구PC 디버그 창 중 로그인 화면이 떴던 포트(9228)는 사람이 로그인해야 한다. 로컬탐은 현황만 보고한다.

## 클라우드 탐이 하는 일 (로컬 크레딧을 쓰지 않는다)
- **C1 타미 재실행 3건**(제미나이 검색 보충 리서치, 덱스 3차, 제미나이 웹 확인 신PC 부분): L1 완료 푸시를 받으면 클라우드 탐이 `tasks/pending/`에 발주한다.
- **C2 구PC 폴러 감시 설치**: 타미(ssh)에게 발주, 대장 등록 PR은 클라우드 탐이 연다.
- **C3 텔레그램 답장 접수 준비**: 타미가 봇 겹침을 읽기 전용으로 확인한 뒤 설치(새 봇이 필요하면 사장님 몫).
- **C4 Slack 중계 켜기**: 사장님이 웹훅을 만들어 저장소 비밀값에 넣으면 시험 재개.
