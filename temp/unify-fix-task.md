## 해야 할 일
아래 작업을 순서대로 수행하라. 결과와 증거는 모두 보고서에 담는다.

### 1. 코드 검증 (code reading)
`mailbox/mailbox_courier_new.py`를 읽고 아래 항목을 각각 검증하라.

(1) `--dry-run` 옵션: 실제 텔레그램 발송 없이 메시지/상태 변경 내용을 화면 출력만 하고, 상태 파일은 dry-run에서 쓰지 않는가.
(2) boss_key 인자 버그: `should_send_to_boss_today`가 state만 받고 boss_key 인자가 없는가.
(3) timedelta 오류: timedelta를 쓰되 import 되었거나, 쓰지 않는가.
(4) 사장님 앞 알림 문구: 지시서 확정 초안을 따르는가.
    - 알림형(요청: 헤더 없음): `탐 : 사장님, 알려드려요. <제목>.`
    - 확인 부탁형(요청: 헤더 있음): `탐 : 사장님, 확인 부탁드려요. <제목>. <요청 문장 그대로>`
    - 이모지는 맨 앞 📬 하나만 허용.
    - 기존 '📬 긴급 우편 | ...' 양식체 사용 금지.
(5) 다른 에이전트 앞 긴급 알림도 같은 형식(받는이만 바꿈). 긴급 없는 우편은 보내지 않는가.
(6) 하루 20건 상한, 저녁 21:00 요약, 쌓인 우편 요약 1건 처리가 구현되어 있는가.

각 항목에 대해 충족/미달을 판정하고, 미달이면 정확한 위치와 수정 방법을 구체적으로 보고하라.

### 2. 발견된 미준수 항목 수정
현재 내가 확인한 바로는 아래 항목이 지시서 문구와 불일치할 가능성이 높다. 코드를 직접 읽고 확인 후, True이면 수정하라.

- `build_message_forBoss` (166-173행): 현재는 `📬 {sender}→사장님: {subject}` + `👉 {ask}`. 지시서 문구로 바꿔야 한다.
- `build_message_others` (175-184행): 현재는 `📬 긴급 우편 | ...` 양식체. 지시서 문구(발신자 표시 `이름 : 받는이, ...`)로 바꿔야 한다.
- `build_boss_overflow_message` (236-238행): 현재는 `📬 오늘 쌓인 우편 {total_unread}건`. 지시서 문구 `📬 사장님 앞 우편 N건 쌓임` 검토.
- 제목 끝 마침표 중복 정리, 한 줄 길이 제한(문장 단위 자르기) 처리 확인.

**중요**: 수정은 `mailbox_courier_new.py` 자체에 가한다(운영 파일 아님). 수정 전 코드 상태를 보고하고, 수정 후 코드 상태를 다시 보고하라.

### 3. dry-run 시나리오 테스트 (증거 캡처)
수정 후(또는 미수정 방치 시) 아래 시나리오를 `mailbox_courier_new.py --dry-run`으로 돌려 출력을 증거로 남겨라.

테스트 환경:
- 테스트 메일함 폴더들: `mailbox/사장님_테스트/`, `mailbox/마야_테스트/`, `mailbox/탐_테스트/` 아래 파일들.
- 상태 파일은 기본 경로 대신 임시 파일 사용. `--state-file` 인자가 없다면, 헤르메스가 당분간 `--state-file`을 추가하도록 코드를 수정하거나, 테스트마다 상태 파일을 백업/복구하는 방식으로 격리하라. 어떤 방식이든 각 시나리오가 서로 간섭하지 않게 하라.
- TELEGRAM_BOT_TOKEN 등 민감 값은 출력에서 마스킹하라. `print` 문에서 token/chat_id가 그대로 노출되지 않도록 확인.

시나리오:
(a) 사장님 앞 우편 1건 → 알림형 1줄 출력 확인
(b) 사장님 앞 3건 누적 → 요약 1건 출력 확인 (메시지가 `📬 사장님 앞 우편 3건 쌓임` 꼴인지)
(c) 긴급 표시 있는 다른 에이전트 앞 우편 → 보낼 메시지 출력 확인
(d) 긴급 없는 다른 에이전트 앞 우편 → 출력 없음(보내지 않아야 함) 확인
(e) 하루 20건 초과 상태 → 21:00 요약 1건 처리 확인 (또는 상한 도달로 추가 발송 없음 + 요약 처리 확인)
(f) 상태 파일이 예전 형식(목록)일 때 → 자동 변환 후 정상 동작 확인

각각에 대해: 종료 코드, 화면 출력 전문(마스킹 포함), 기대와의 일치 여부를 기록하라.
