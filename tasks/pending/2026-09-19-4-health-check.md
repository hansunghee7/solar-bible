읽는 방법: 이 파일 전체를 읽고 수행한다. 요약본만 보고 수행하지 않는다.

목표: 아래 6개 점검을 PASS/FAIL 한 줄씩 출력하는 스크립트를 만든다. LLM을 부르지 않는다.
위치: C:\Users\PC\AppData\Local\hermes\scripts\health_check.py

점검 6개:
1. hermes 크론 작업별 last_status 와 마지막 실행 후 경과. 경과가 주기의 3배를 넘거나
   status가 error면 FAIL. (paused 작업은 PAUSED로 따로 표시)
2. LiteLLM  http://127.0.0.1:4000/health/liveliness 가 200이면 PASS
3. 4090 Ollama  config.yaml 의 fallback 항목에 적힌 주소의 /api/tags 가 200이면 PASS
4. OpenRouter  https://openrouter.ai/api/v1/models 가 200이면 PASS (키 사용 안 함)
5. Open WebUI  http://127.0.0.1:3000/ 가 200이면 PASS, 게이트웨이 http://127.0.0.1:8642/v1/models
   가 401 또는 200이면 PASS
6. 디스크: D: 의 Get-PhysicalDisk HealthStatus 가 Healthy면 PASS, C: 와 D: 여유공간 15% 미만이면 FAIL

출력 규칙: 한 줄에 "PASS|FAIL 이름 근거". 키·토큰은 절대 출력하지 않는다.
config.yaml 은 읽기만 한다(수정 금지). 스크립트는 UTF-8로 출력하도록 만든다
(relay_watcher.py 상단 sys.stdout.reconfigure 참고).

절차: 스크립트 작성 → 직접 1회 실행해 출력 원문 → 스크립트 크론으로 등록
(script 방식, 30분 주기, 에이전트 모델 없음) → hermes cron list 원문.
크론 등록은 직접 실행이 종료 코드 0일 때만 한다.

금지: 알림 전송 기능 추가, 기존 크론 수정, config.yaml 수정.
보고서에 IP 주소와 호스트명을 쓰지 않는다(공개 저장소).
15턴 안에 못 끝나면 스크립트 초안 경로와 남은 단계를 보고하고 멈춘다.

완료 기준: 직접 실행 원문(6줄), 크론 등록 원문, 다음 예약 실행 뒤 last_status ok 원문

## 공통 규칙 (이 지시서 전체에 적용)

보고 서식 (이 순서를 지킬 것, 칸을 생략하지 말 것)
TASK: 무엇을 하라고 했는가 (한 줄)
EXECUTION: 실제로 실행한 명령
OBSERVATION: 명령이 실제로 출력한 결과 (요약하지 말고 핵심 줄 그대로)
VERIFICATION: 완료 기준 각각에 대해 통과/실패
STATUS: DONE / 실패 / 일부만 완료 (셋 중 하나만)

- 작업 위치: 지시서에 적힌 절대 경로에서만 작업한다. 작업 전에 그 경로에서
  git status -sb 원문을 붙인다. 새 클론을 만들지 않는다.
- "running", "실행 중", "예약됨"은 완료가 아니다. 결과 로그나 출력 원문이 있어야 DONE이다.
- 금지 표현: "적용 완료(변경 안 함)"처럼 뜻이 부딪히는 문장. 바꿨으면 "바꿈", 안 바꿨으면 "안 바꿈".
- 확인하지 못한 것은 "확인 못 함"으로 쓴다. 추측을 사실처럼 쓰지 않는다.
- 비밀값(API 키, 토큰, 비밀번호)은 출력·기록하지 않는다. 보고서에도 쓰지 않는다.
- 이 저장소(solar-bible)는 공개다. 보고서와 커밋에 호스트명, IP 주소, 사용자 계정명,
  개인 파일명을 쓰지 않는다. 필요하면 <호스트>, <사용자>, <IP>로 표기한다.
- 파일·폴더 삭제, 이동, 덮어쓰기 금지 (이 지시서가 명시한 것 제외).
  D 드라이브 안의 어떤 것도 지우거나 옮기지 않는다.
- 파일·폴더 경로는 지시서에 적힌 것만 쓴다. 큰 파일을 찾으려고 C:\ 같은 넓은 범위를
  재귀 스캔하지 않는다. 경로가 없으면 스캔하지 말고 "경로 없음"으로 보고하고 멈춘다.
- 출처를 적을 때는 실제로 읽은 파일 종류를 그대로 쓴다(추측으로 채우지 않는다).
- 최종 보고 원문은 화면에만 두지 말고 C:\work\solar-bible\tasks\done\ 의 이 지시서
  파일 아래에도 남긴다.
- 막히면 멈추고 막힌 이유를 보고한다. 우회하지 않는다.
- 15턴 안에 못 끝나면 "여기까지 했고 다음은 이것"을 보고하고 멈춘다.
