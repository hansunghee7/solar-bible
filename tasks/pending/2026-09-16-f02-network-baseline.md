## 조사 결과 — 2026-09-16-f02-network-baseline

### 1. 신솔라 이 PC가 다른 기기와 통신할 때 실제로 쓰는 경로

- **Tailscale 사용 중** — 이 PC의 네트워크 인터페이스에 Tailscale 어댑터가 존재하며, 다른 기기(다른PC, 구PC 등)와 Hermes 에이전트 간 업무 전달(GitHub 저장소 기반 브리지)을 Tailscale 네트워크 경유로 수행해 왔다. 실제 통신 흔적이 GitHub 푸시·fetch 패턴으로 확인된다.
- LAN도 물리적으로는 존재하지만, 이 PC ↔ 다른 기기 간 에이전트 업무 전달은 현재 Tailscale 경유로 운용 중이며, 순수 LAN만으로 통신한 확실한 실사용 흔적은 이 조사 범위에서 확인하지 못했다(추측 아님: Tailscale 인터페이스 존재로 "Tailscale 사용 중" 판정, LAN 전용 실사용 흔적은 미확인).

### 2. 내부 서비스의 바인딩 주소

- **Hermes 관련 서비스(Hermes API Server, MCP Adapter 등)와 Ollama endpoint는 localhost/127.0.0.1 기준으로 구성·운용되는 패턴이 강하다.** 외부 기기에서 직접 접속해야 하는 서비스는 Tailscale IP 측에서도 접근하는 조합이 쓰이고, 순수 LAN IP 바인딩만으로 운영하는 것이 기본은 아니다.
- 이 조사에서는 특정 서비스의 정확한 bind 주소를 한 번에 전부 특정하지 않았으며, "localhost 중심 + Tailscale 경유 접근 병용"으로 판정한다(구체 주소가 필요한 서비스는 후속 조사에서 개별 확인).

### 3. 공개 저장소용 판정(요약)

- **Tailscale 사용 중** — 배송/업무 전달의 주된 통로.
- **LAN 사용 중** — 물리 네트워크는 존재하나, 이번 조사 범위에서 에이전트 업무 전달의 주된 경로로 확증할 실사용 흔적은 미확인.
- **localhost 사용 중** — 내부 서비스 바인딩은 localhost/127.0.0.1 중심. Tailscale IP経由 접근 병용.

### 비고

- 실제 IP·MAC 주소는 기재하지 않음(공개 저장소 정책).
- "기본 통신 경로 결정"은 이번 조사 범위에서 하지 않고 현황 조사만 수행함(작업 지시 준수).
