## 작업 2: 자율 폴링 루틴 구축 (가장 중요, 사장님 relay를 없애는 작업)

사장님이 매번 신솔라를 직접 불러서 tasks/pending/을 확인시키는 게
피로하다고 하셨다. 이제부터 탐은 이 저장소의 tasks/pending/에 파일을
직접 써서 작업을 맡기고, tasks/done/과 진행상황.md를 직접 읽어서 결과를
확인한다 - 사장님이 중간에서 내용을 옮길 필요가 없게 만드는 게 목표다.

이게 되려면 신솔라가 **사람이 불러주지 않아도 스스로 주기적으로**
(예: 10~15분마다) 다음을 해야 한다:
1. `git pull origin main`으로 저장소 최신화
2. `tasks/pending/`에 새 작업 파일이 있는지 확인
3. 있으면 `hermes chat --oneshot --query "..."`로 1회 처리
4. `tasks/done/`으로 옮기고 push

Hermes 자체에 예약 실행(cron 유사) 기능이 있는지 확인하고, 있으면 그걸
써서 이 루프를 구성한다. 없으면 OS 스케줄러(Windows 작업 스케줄러 등)로
같은 스크립트를 주기 실행시킨다. 구성 방법과 실제로 몇 분 주기로
도는지를 `tasks/done/`에 결과로 남긴다.
