# 헤르메스 카드: 핏 자동 실행 환경 읽기 전용 수집 (탐 -> 헤르메스)

읽기만 하는 작업이다. 파일 수정·삭제, 프로세스 종료·재시작, 설정 변경을 하지 마라. 키·토큰·계정 정보·채널명은 파일에 쓰지 마라. 이 저장소에는 결과 내용을 올리지 마라.
1. 폴더 `C:/work/_ops/orch`가 없으면 만든다.
2. `C:/work` 아래에서 파일 이름이 `trial_1015.log`인 파일을 찾는다. 찾으면 경로, 마지막 수정 시각, 마지막 20줄을 `C:/work/_ops/orch/fit_linux_check.txt`에 적는다. 못 찾으면 "trial_1015.log 없음"이라고 쓴다.
3. 같은 파일에 현재 실행 중인 프로세스 중 이름에 `ffmpeg`, `build_final`, `python`이 든 것의 이름과 시작 시각만 적는다(명령줄 인자는 쓰지 마라).
4. `hermes cron list` 출력의 작업 이름과 마지막 실행 시각만 같은 파일에 적는다.
끝 조건: 파일이 있으면 끝. 보고는 "저장함, trial_1015.log 있음/없음" 한 줄만.
