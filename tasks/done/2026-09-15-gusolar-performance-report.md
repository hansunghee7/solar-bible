## 판정

- **구PC는 LLM 연산에 쓸 수 없다.** GTX 650 1GB VRAM은 최소 요구(4GB+)에
  크게 못 미치고, CPU도 2012년형이라 병렬 워크로드에 치명적으로 느리다.
  이건 프로세스 정리로 해결되는 문제가 아니라 하드웨어 한계다 —
  solar-bible.md §14가 이미 정한 구조("구솔라는 실행 시 신PC 4090의
  지능·리소스를 쓴다")가 맞는 방향이고, 추가 검증할 필요 없다.
- 불필요 상주 프로세스는 있다(Epson 프린터 유틸리티, Riot Client/Lunar
  Client 게임 런처, Google Drive File Stream, Edge 자동 시작). 제거하면
  가벼운 GitOps 폴링 작업(파일 읽고 쓰기 수준)엔 도움이 되지만, 구PC를
  연산 자원으로 쓸 수 있게 만드는 수준의 효과는 아니다.
