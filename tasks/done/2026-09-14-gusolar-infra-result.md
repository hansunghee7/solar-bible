# 구PC(구솔라) 인프라 조사 결과

- 조사자: 구솔라 (이 세션은 신PC=신솔라 쪽에서 열렸음 — 구PC가 아님)
- 조사 방식: 이 세션에서 구PC 직접 접근 수단(SSH/WinRM/Tailscale 대상 자격 등)이 사전 구성돼 있지 않아, 구PC 사양·텔레그램 연동·Wake-on-LAN을 실제 조회하지 못함. 기존 `tasks/done/2026-09-14-infra-survey.md` 와 아래 솔라바이블 §14/역할노트 기반 문서 조사만 수행.

## 1. 구PC 사양 (CPU·RAM·GPU·SSD/HDD)

- **FACT**: 현재 이 세션 호스트는 신PC(DESKTOP-2UDNSLS, AMD Zen 5 계열, RAM 약 64GB급, GPU RTX 4090 24GB, C:/ 약 1TB NVMe + D:/ 약 8TB 저장 드라이브, Windows 11 Home)임. 구PC가 아님.
- **FACT**: 이 세션에서 구PC로 보이는 Tailscale 윈도우 노드가 idle 상태로 떠 있으나, 해당 노드로의 접근 자격(SSH 키/계정, WinRM, 대상별 Tailscale 권한 등)을 이 자리에서 확인하지 못함.
- **INFERENCE**: 구PC 사양은 이전 infra-survey(`tasks/done/2026-09-14-infra-survey.md`)에서도 "직접 조사 불가"로 남았고, 이번도 동일. 구PC 호스트명 후보로 `desktop-202ap4o` 계열이 언급된 흔적은 있으나 동일 여부도 미확인.
- **UNKNOWN**: 구PC CPU 모델·코어 수, RAM 용량, GPU 모델·VRAM(존재 시), SSD/HDD 용량·유형, OS 버전은 구PC에 실제 접근하기 전까지 알 수 없음.
- **결론**: 구PC 사양은 이 세션에서 조사 불가. 아래 "사장님 확인 필요" 항목으로 넘김.

## 2. 텔레그램 봇 연동 여부

- **FACT**: 이 세션 호스트(신PC)에는 Hermes `hermes send --list telegram` 결과 텔레그램 대상 `telegram:Simon [8609932977]`이 등록되어 있음 → 신솔라(이 세션) 쪽 텔레그램 연동 대상이 존재함. 토큰 값·채팅 상세는 기재하지 않음(§10 준수).
- **UNKNOWN**: 구PC(구솔라) 쪽 Hermes가 실제로 텔레그램 봇에 연결돼 있는지는 구PC 접근 불가로 이 자리에서 확인 불가. 구솔라는 현재 Sleep 상태라는 문서상 설명과 배치되지 않음.
- **결론**: 구PC 텔레그램 봇 연동 여부는 "구PC 접근 가능해지면 실제 확인 필요, 현재 확정 불가".

## 3. Wake-on-LAN 설정 여부

- **FACT**: 이 세션은 신PC에서 실행 중이며, 구PC 전원·BIOS·OS 네트워크 설정(WoL 수신, 매직 패킷 발송 수단, Tailscale WoL 등)을 조회하지 못함.
- **UNKNOWN**: 구PC 쪽 WoL 설정 여부(예/아니오)는 확인 불가. 이 저장소(공개)에는 MAC/IP 등 구체 식별자를 적지 않음 — 판정만 필요.
- **결론**: 구PC Wake-on-LAN 설정 여부는 "설정 여부 확인 불가, 사장님 확인 필요".

## 4. 구PC 직접 접근 가능해지면 확인할 항목 (사장님 확인 필요)

아래 항목은 구PC 접근 수단 확보 후 실제 조회해 채울 값. 지금은 비워 둠.

1. 구PC 식별: 추정 노드(`desktop-202ap4o` 계열 등)와 실제 구PC가 같은지 확인
2. CPU: 모델·코어 수
3. RAM: 용량
4. GPU: 모델·VRAM 유무·용량
5. 저장장치: SSD/HDD 용량·유형 (예: "NNNGB NVMe SSD + NNNGB HDD" 형태)
6. OS: 버전
7. 원격 접근 수단: SSH/WinRM 등 설정 여부, 필요한 계정·키(별도 안전한 채널로 전달)
8. 텔레그램 봇 연동: 실제 연결돼 있는지 여부(토큰 값 아님)
9. Wake-on-LAN: 설정됨/안 됨 (MAC/IP 제외)

## 5. 이 세션에서 확정 가능한 것 (구PC 관련)

- 구PC는 현재 Sleep 상태라는 점이 문서상에서 확인됨(솔라바이블 §14, `docs/역할노트-구솔라.md`).
- 구PC와 신PC는 Tailscale 네트워크 레벨로 연결돼 있음(이전 infra-survey에서 확인된 사항, 상태값 기준).
- 신↔구솔라 간 작업 전달은 이 저장소(GitHub) `tasks/pending/` → 처리 → `tasks/done/` → push 흐름(GitOps)이 실제 사용됨. 구솔라는 자동 폴링을 하지 않으므로, 큐가 섞여도 실행 사고로 이어지진 않지만 전달 주체(신솔라·사장님)가 "받는 이"를 보고 전달해줘야 함.
- 구PC 사양/텔레그램/WoL은 이 세션에서 실제 값 조회 불가 → 전부 "확인 불가, 사장님 확인 필요".
