Anthropic 공식 문서 기준으로 Claude Code 웹/클라우드 세션이 GitHub PR 활동(댓글, CI, 리뷰)을 구독해 알림으로 받는 기능과 외부 웹훅·예약 작업(루틴)의 API 발동 기능이 있는지, 있다면 제한(인증 방식, 자기 계정 댓글 처리 포함)을 공식 문서 주소와 함께 알려 줘.
GitHub 이슈·PR 댓글 이벤트를 받는 에이전트나 앱이 같은 계정이 단 댓글과 github-actions 봇이 단 댓글을 다르게 취급하는 일반적 설계(자기 이벤트 무시 규칙)가 있는지, 공식 문서나 신뢰할 만한 자료로 근거를 알려 줘.
2026년 10월 기준 Tally 웹훅을 받아 GitHub 저장소에 파일을 만드는 변환 함수를 GCP Cloud Run 함수, Cloudflare Workers, GitHub Actions 중 어디에 두는 것이 1인 규모에서 가장 단순하고 싼지, 각각의 무료 한도와 함께 출처를 붙여 비교해 줘.
방화벽 안쪽 Windows PC에서 GCP Pub/Sub StreamingPull을 상시 감시 스크립트로 돌릴 때 실무에서 주의할 점(인증, 재연결, 중복 수신, 윈도우 서비스 등록)을 공식 문서와 사례 출처와 함께 알려 줘.
