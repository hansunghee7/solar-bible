규정 원문:
- 자격증명(API 키 등)이 내부 에이전트(우리 크루 세션)에게만 노출된 것은 교체 사유가 아닙니다. 교체를 권하지 마세요.
- 교체하는 경우는 외부로 노출됐을 때만입니다: 공개 저장소에 커밋·푸시, 외부인에게 전달(메일, 채팅), 외부 서비스의 로그나 공유 문서에 값이 남음, 크루에 외부인이 합류.
- 어느 경우든 키 값은 화면·로그에 출력하지 않습니다(마스킹).
- 키 파일이 공개 저장소 폴더 안에 있으면 교체 대신 커밋을 막는 설정(.gitignore, 로컬 변경 무시)을 먼저 겁니다.
