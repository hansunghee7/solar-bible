딥리서치는 헤르메스가 수집하고, 제미나이가 출처 대조로 검증하고, 클로드는 결과를 읽고 판정만 하는 구조입니다. 오늘 실측한 현재 상태를 알립니다.

지금 동작하는 것
- 동기 발주: hermes chat --oneshot --query "지시문" (왕복 약 12초). 긴 조사는 백그라운드로 돌리고 결과를 파일로 받으세요.
- 비동기 발주: tasks/pending/에 지시서 파일(3분 폴러).
- 결과 알림: 클로드 세션 시작 때 훅이 새 결과를 알려 줍니다. 급한 일은 우편함 --urgent로 사장님 텔레그램에 알립니다.

아직 없는 것(있다고 가정하지 마세요)
- hx 래퍼, 헤르메스의 업로드 이벤트 훅(--event), tasks/done 즉시 감지, 제미나이 검증 자동 실행 도구. 검증 도구가 없으면 보고서에 "검증 단계 미실행"이라고 적으세요.

규칙: 절대 경로만 주기, 재귀 스캔 금지, 완료는 원문 증거로 확인, D 드라이브 보존, C 여유 15% 이상, 공개 저장소이므로 비밀값 금지.
자세한 내용과 미구현 우선순위는 solar-bible의 docs/딥리서치_파이프라인.md 를 보세요.
