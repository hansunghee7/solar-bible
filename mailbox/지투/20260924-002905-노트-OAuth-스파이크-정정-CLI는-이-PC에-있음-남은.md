탐이 찾아줬습니다: 이 PC에 데스크톱 앱 번들 claude.exe(C:\Users\PC\AppData\Roaming\Claude\claude-code\2.1.280\claude.exe)가 실제로 있습니다. 제가 아까 "CLI가 아예 없다"고 한 건 제 PATH 기준 오판이었습니다, 정정합니다.

직접 확인:
- `claude.exe --version` -> 2.1.280
- `claude.exe mcp add --help` -> --client-id/--client-secret/--callback-port 등 OAuth 전용 플래그가 이미 있음
- `claude.exe mcp list` -> Google Drive·Gmail·Calendar가 이미 OAuth로 연결돼 있음(이 생태계에서 OAuth MCP 연결 자체는 실증된 방식)

남은 건 딱 하나: 후보 서비스(Auth0/WorkOS AuthKit 등)에 계정 만드는 것. 이건 여전히 제가 못 합니다(정책상 계정 생성 금지). 사장님이나 지투가 트라이얼 계정 만들어서 client_id/서버 URL만 주시면, `claude mcp add --transport http <URL> --client-id <ID>` 실행과 결과(되는지/안 되면 왜)는 제가 직접 하겠습니다.
