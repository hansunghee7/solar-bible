마야 라이팅 검수 회신 (2026-10-22 밤)

범위: 지투가 보낸 변경 목록(demo_guide_update_1022.md)의 새 문장만 봤습니다. draft v7(코디스), v9(라이덕) 본문은 열어 보지 못했습니다. 본문 문장이 다르면 본문 쪽을 따르고, 아래 제안은 본문 문장에 같은 기준으로 옮겨 주세요.
기준: BIBLE 라이팅 56(사용자를 주어로, 명확·간결·쓸모), 41(말투 하나), 46(전문 용어는 처음에 쉬운 말 한 줄), Carvit UX 1.28(내부 용어 금지).

고칠 문장(절 번호, 원문, 제안)

1. 공통 2, "이 가이드의 값이 바이블(BIBLE_UX_PLAYBOOK/BIBLE_WRITING)과 다르면 이 가이드가 이긴다. 다르게 정한 곳은 '바이블 N과 다름: 이유' 한 줄을 그 절에 남긴다."
   제안: "이 가이드의 값이 Carvit 기본 가이드(BIBLE_UX_PLAYBOOK, BIBLE_WRITING)와 다르면 이 가이드를 따라요. 다르게 정한 곳에는 'Carvit 기본 가이드 N과 다름: 이유'를 그 절에 한 줄 남겨요."
   이유: "바이블"은 팀 안에서 쓰는 말이라 처음 나올 때 쉬운 말 한 줄이 필요합니다(46, 1.28). "이긴다"는 겨루는 말투라 "따른다"로 바꿨습니다.

2. 공통 3, "Carvit UX 공통 절 1.52~1.56(첫 사용 안내·AI 근거·진행 말하기·상황별 문구·쉬운 용어)"
   제안: "Carvit UX 공통 절 1.52~1.56(첫 사용 안내, AI 답변의 근거, 진행 상황 말하기, 상황별 문구, 전문용어와 쉬운 말)"
   이유: 1.56의 실제 제목은 "UX 전문용어는 쉬운 말과 함께 찾을 수 있게 둔다"라서 "쉬운 용어"로 줄이면 뜻이 달라집니다. 1.52, 1.53, 1.55는 제목과 맞습니다. 1.54("진행 말하기")는 제가 제목을 확인하지 못했으니 노트가 제목과 대조해 주세요.

3. 공통 4, "바이블/Carvit의 '라이트 고정' 규칙은 Carvit 제품 화면에만 적용된다."
   제안: "Carvit 기본 가이드와 Carvit 제품 가이드의 '라이트 고정'(밝은 화면만 쓰는 규칙)은 Carvit 제품 화면에만 적용돼요."
   이유: "바이블/Carvit"처럼 슬래시로 붙이면 무엇을 가리키는지 흐려집니다. "라이트 고정"에 뜻 한 줄을 붙였습니다(46).

4. 코디스 4절, "대체 순서: Inter → Noto Sans KR → 시스템 고딕"
   제안: "대체 순서: Inter → Noto Sans KR → 기기 기본 고딕 글꼴"
   이유: "시스템 고딕"은 개발자 말입니다. 나머지 문장(Google Fonts에서 둘 다 불러올 수 있다)은 그대로 좋습니다.

5. 코디스 줄바꿈, "한글 문구는 단어 중간에서 줄을 바꾸지 않는다(word-break: keep-all), 영어는 기본값."
   제안: "한글 문구는 단어 중간에서 줄을 바꾸지 않아요(word-break: keep-all). 영어는 기본 설정 그대로 둬요."
   이유: "기본값"을 쉬운 말로 풀었습니다. 문서 톤이 합니다체나 평서체면 해요체를 쓰지 말고 문서 어미에 맞추세요(41, 한 문서 안에서 말투를 섞지 않는다).

6. 라이덕 서체 절, "...글자 크기를 `--fs-metric` 같은 CSS 변수 블록으로도 적어 list_tokens가 서체 크기를 읽게 한다"
   제안: "...글자 크기도 `--fs-metric` 같은 CSS 변수 블록으로 적어요. 그러면 에이전트가 글자 크기 값을 읽을 수 있어요."
   이유: 가이드 본문에 도구 이름(list_tokens)이 들어가면 고객 에이전트에게 내부 말이 됩니다. 이 설명은 노트의 작업 메모에 두고, 가이드에는 이유만 남기세요.

7. 라이덕 19절, 문서형 아티팩트 폭을 "미정(읽지 못한 것)"에 한 줄 추가
   제안: "문서형 화면의 본문 폭: 아직 정하지 않았어요."
   이유: "아티팩트"는 처음 나오는 곳에서만 "(Claude가 만든 화면 파일)"처럼 한 줄 풀이를 붙이세요(46). 숫자는 넣지 않았습니다(이번 범위 밖).

수정 없음: 공통 1(번호=제목), 코디스 서체의 "Google Fonts에서 불러올 수 있다" 문장, 라이덕 줄바꿈 문장(위 5번과 같은 기준으로 어미만 문서에 맞추세요).
