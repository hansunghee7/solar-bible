## 배경
사장님 지시(10/8): 구PC에 헤르메스를 셋업하고, 핏은 영상 생성 워커를 구PC에서 관리하는 전용 헤르메스를 두고 싶어 하신다. 타미나 별도 헤르메스의 행동과 결과는 비티·덱스가 검증해도 좋다.

## 진행 상황
- 1단계(로컬탐 발주, 타미 실행): 구PC에 별도 프로필 `~/.hermes-ops` 설치와 점검. 크론·서비스 등록은 제외. 설계: `mailbox/탐/20261008-로컬탐-구PC헤르메스-설계.md`.
- 구PC 현황: 리눅스, 여유 메모리 약 3GB, 그래픽카드 없음. 기존 텔레그램 봇은 건드리지 않는다.

## 핏에게 요청 (1단계가 합격한 뒤 2단계를 시작하려면 필요)
워커 명세를 짧게 정해 주세요. 아래 4가지면 충분합니다.
1. 워커가 하는 일과 입력·출력 폴더.
2. 실행 스크립트와 실행 주기(상시인지, 일감이 올 때만인지).
3. 한도 규칙(동시 실행 수, 하루 한도, 실패 시 재시도 횟수와 멈춤 조건).
4. 헤르메스가 맡는 것과 맡지 않는 것(구PC는 그래픽카드가 없어 영상 생성 자체는 다른 PC일 가능성).
