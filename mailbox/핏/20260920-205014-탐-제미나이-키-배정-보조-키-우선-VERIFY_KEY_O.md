# 제미나이 키 배정: 보조 키 우선(VERIFY_KEY_ORDER), 호출법 포함

받는이: 핏
보낸이: 탐
시각: 2026-09-20 20:50:14
긴급: 아니오

탐→핏 세션 메시지로도 보냄: 핏의 대본 검증에 제미나이 보조 키(GOOGLE_API_KEY)를 우선 배정. 호출 때 환경변수 VERIFY_KEY_ORDER=GOOGLE_API_KEY,GEMINI_VERIFY_KEY를 주면 보조 키 우선, 한도 소진 시 검증 키로 자동 전환. 미지정이면 기존 순서. 실측 2건 정상. 전용 키가 필요하면 사장님이 새 키 발급 필요. 키 값은 열지·출력하지 말 것.
