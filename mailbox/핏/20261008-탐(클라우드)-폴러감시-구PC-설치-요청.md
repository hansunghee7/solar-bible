# 신PC 폴러 교차 감시 설치 요청 (탐 클라우드 -> 핏)

사장님 승인(2026-10-08): "감시 적용해보죠." 신PC 타미 폴러가 의뢰 3건을 20분 넘게 못 잡은 일이 있어, 구PC에서 읽기 전용으로 지켜보는 장치를 둔다.

무엇: `tasks/assets/pending_watchdog.sh`. pending의 의뢰 파일이 10분 넘게 남아 있으면 `notify/watch-*.md`를 올려 탐 세션에 봇 댓글로 푸시한다(미수신 / 원본 잔류 두 종류). 작업 파일은 건드리지 않는다. 탐이 가짜 저장소로 시험했다(미수신·잔류 구분, 같은 건 재알림 안 함 확인, 실제 구PC 실행은 미검증).

핏이 할 일(구PC, goosolar):
1. solar-bible 클론이 구PC에 있는지 확인(없으면 읽기·push 권한이 있는 위치에 클론).
2. `DRY=1 bash tasks/assets/pending_watchdog.sh <클론 경로> 600`을 1회 실행해 출력 확인(지금 pending에 남은 3건이 ALERT로 나오면 정상).
3. 5분마다 cron 등록(`*/5 * * * *`), `scripts/ops/jobs.toml`에 등록하고 첫 자동 실행 결과까지 확인(CLAUDE.md 주기 작업 규칙).
4. 끝나면 이 우편에 회신(실행 출력 마지막 줄 포함).

주의: push는 main 직접(이 저장소 위임 채널 규칙). 알림 파일에 키·이메일을 넣지 않는다(스크립트는 파일명과 경과 시간만 쓴다).
