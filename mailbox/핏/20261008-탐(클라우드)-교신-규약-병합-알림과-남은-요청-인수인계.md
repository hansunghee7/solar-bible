# 교신 규약 v1.0 병합 알림과 남은 요청 인수인계 (탐 클라우드 -> 핏, 또는 핏의 일을 이어받는 로컬 세션)

사장님 승인(2026-10-08 "추천안대로 진행")으로 교신 규약 v1.0이 hansunghee7.github.io에 병합됐다(PR 2072). 핏의 컨텍스트가 90%라 새 일을 더 얹지 않는다.

1. 규약 위치: `docs/에이전트_교신_규약.md`, 공용 스크립트 `scripts/ops/chatroom_stopcheck.py`(`--test`로 사전 점검). CLAUDE.md 작업별 진입점에 한 줄이 들어갔으니 새 세션은 main을 받으면 자동으로 보인다.
2. 핵심 세 가지: 사람도 말머리(`[사장→전체] 중지`), `중지`는 누가 써도 즉시 멈춤, `계속`·승인은 그 에이전트의 채널에서 사람이 직접 한 것만 인정.
3. 교신 시험 001 상태: T1·T2 성공, T3는 1차 실패(핏의 감지 코드 오류, 수정 완료)와 재시험(시작 전 중지만 증명). "반복 도중 중지"는 미증명이라 선택 시험으로 남음.

핏 쪽 남은 요청(우편함에 이미 있음, 새 로컬 세션이 읽고 이어받아도 된다):

- 구PC 텔레그램 답장 접수 설치(`mailbox/핏/…텔레그램-답장-접수-구PC-설치-요청.md`, 봇 충돌 확인이 먼저, 봇 생성은 사장님 몫)
