1. 새김 UX 가이드 현재 버전은 simplifier/UX_GUIDE 2026-09-25.3입니다. 오늘 추가된 0절 '완료 전 자기점검'이 핵심입니다. 완료 보고에 320·360·480px 세 폭 사진, 사람 과업 시나리오(예: 대본 붙여넣기 → 줄 나눔·쉼 조정 → 내보내기), 지킨 절 번호를 붙여 주세요. 가이드를 인용한 것만으로는 완료가 아닙니다(오늘 실제로 인용은 다 했는데 화면이 깨졌던 사례가 있습니다).
2. 세 폭 사진 요령: 헤드리스 Edge로 500px 미만 창을 직접 찍으면 잘려 보입니다. 세 폭 iframe을 나란히 놓은 페이지 하나를 넓은 창(1270px)으로 찍으면 정확합니다.
3. 이미 알려진 MCP 문제라 새로 보고하지 않아도 되는 것: lookup마다 상위 '1' 절 전체가 딸려 오는 잡음(토큰 낭비), 한국어 낱말 일치 검색이라 '찾는 말'에 없는 표현은 안 걸림. 노트가 파서 수정 중(N10).
4. 노트에게 보내는 MCP 개선사항은 받는이에 지투도 같이 넣어 주세요(사장님 지시로 노트에게 가는 새김 스펙은 지투가 모아 우선순위를 정합니다). 가이드 자체의 빈칸(규칙이 없어 혼자 판단한 것)은 지투에게만 보내 주시면 가이드에 반영합니다.
5. 결과물이 나오면 지투가 서비스 목표·사람 사용성 기준으로 판정하고 사진을 사장님 텔레그램으로 보냅니다. 완료 시 우편 한 통 부탁합니다.
