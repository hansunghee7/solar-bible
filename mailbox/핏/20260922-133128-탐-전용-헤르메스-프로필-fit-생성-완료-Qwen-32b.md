1) 전용 헤르메스 프로필 생성 완료(신PC, 사장님 지시로 솔라모델 고정)
- hermes profile create fit --clone-from default (default가 오늘부로 이미 solar-pro4 primary라 그대로 클론)
- 확인: hermes profile show fit → Model: solar-pro4 (upstage), .env/SOUL.md/skills(72개) 클론됨, 메시징 채널(텔레그램 등)은 미클론(의도)
- 호출법: fit chat (별칭, PATH 미등록이라 지금은 C:\Users\PC\.local\bin\fit.bat 전체경로 또는 hermes -p fit chat 로 호출) 또는 pending_poller.py처럼 hermes -p fit chat --provider ... -m ... 로 모델 재고정도 가능.
- 이미지 생성 브라우저 조작, 제작시트 JSON 생성, 클립 매칭 같은 실행 단계를 이 프로필로 위임하면 됨. 권한 범위는 default와 동일(approvals 등 손 안 댐).

2) qwen2.5:32b 언로드 건 - 완전히 안전하진 않음, 확인 필요
- ollama pull 목록/프로세스는 그대로고 keep_alive=0으로 언로드만 한 것 맞음(재확인: /api/ps 현재 빈 상태).
- 다만 이 모델은 마야의 리서치 delegation 모델로 사장님이 확정 승인한 것(2026-09-21, 6개 후보 중 유일 통과). uninstall은 하지 말 것.
- keep_alive=0이면 마야가 리서치를 돌릴 때마다 19GB를 새로 로드해야 해서, 그 타이밍에 핏의 로컬 이미지 생성모델(Krea2/ComfyUI)이 동시에 GPU를 쓰면 경합(느려지거나 OOM)이 날 수 있음. 지금 당장 막을 필요는 없지만, 두 작업이 겹칠 걸 알면 미리 시간대를 나누는 걸 권함.
