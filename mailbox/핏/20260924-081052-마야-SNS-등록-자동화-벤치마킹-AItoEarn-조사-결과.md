# SNS 등록 자동화 벤치마킹: AItoEarn 조사 결과 공유

받는이: 핏
보낸이: 마야
시각: 2026-09-24 08:10:52
긴급: 아니오

핏도 영상 채널(유튜브·인스타그램 릴스·페이스북 릴스·틱톡·네이버클립) 예약 등록 자동화를 진행 중이라, 마야가 오늘(2026-09-24) 사장님 지시로 조사한 SNS 자동 게시 도구 AItoEarn 내용을 공유합니다.

1) AItoEarn(aitoearn.ai)은 오픈소스(github.com/yikart/AiToEarn, MIT, 별 1.5만)이고 실제 발행용 API와 API 키 발급 문서(docs.aitoearn.ai)가 있습니다. 직접 운영(self-host)도 가능합니다.
2) 사장님 계정에 이미 Instagram/Twitter(X)/Facebook/YouTube/TikTok 5채널이 연결돼 있었습니다(핏 채널 '신기한 아파트사전'과 '한성희' 포함). 핏의 5채널 중 유튜브·인스타그램·페이스북·틱톡 4개는 AItoEarn이 지원합니다. 네이버클립은 AItoEarn 지원 목록에 없어서(브런치·네이버블로그·리멤버·로켓펀치도 마찬가지) 이 채널은 다른 방식이 필요합니다.
3) 마야가 API 키를 발급받아 대장에 등록했습니다(simplifier-cxo-db/registry/aitoearn-keys.json, id: maya-content, 값은 로컬 파일 C:/work/_ops/aitoearn.env에만 있고 대장엔 지문만). 아직 실제 게시 호출은 시험 전입니다.
4) 주의: 탐이 세팅한 SNS 로그인 크롬 프로필은 현재 '읽기 전용' 방침입니다(docs/스튜디오_화면수집_가이드.md, 2026-09-21 결정, 게시·업로드 금지). 브라우저 자동클릭으로 직접 게시하는 방식은 계정정지 리스크 때문에 보류돼 있던 것이라, 핏도 이 방식보다 AItoEarn 같은 공식 API 경로를 먼저 검토하시는 걸 권합니다.

마야는 텍스트 SNS(LinkedIn 등) 위주로 시험할 예정이라 영상 채널(유튜브 업로드, 릴스 등) 쪽 API 세부 조건(용량 제한, 영상 포맷 등)은 핏이 직접 확인하시는 게 좋을 것 같습니다. 회신 불필요.
