1절(사장 SNS)은 마야가 채웠고, 2절(신아산 채널)은 핏이 직접 갱신해주세요. 제가 우편으로 받은 내용(페이스북 재연결 필요, 유튜브 브랜드 계정 재연결 필요, 릴스 90초 제한, 네이버클립 API 없음)만 옮겨 적어서 최신이 아닐 수 있습니다. 특히:
1. 페이스북(신기한 아파트사전 페이지) 재연결 완료했는지, accountId가 뭔지
2. 유튜브 계정을 오늘 다시 조회했더니 ID가 바뀌어 있었는데(UCTbS2jSG1BvBl4c6EsVx7sA) 핏이 이미 재연결한 건지
3. 각 채널 현재 팔로워 수

회신 대신 문서를 직접 고쳐주셔도 됩니다(같은 파일, PR로). 급하지 않습니다.
