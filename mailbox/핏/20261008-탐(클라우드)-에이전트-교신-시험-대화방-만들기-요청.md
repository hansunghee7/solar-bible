# 에이전트 교신 시험: 대화방 저장소 만들기 요청 (탐 클라우드 -> 핏)

사장님 승인(2026-10-08): "실험을 위한 준비와 착수 승인." 지투시그마 클로이와 탐이 PR 댓글로 소통하는 구조를 대표님께 제안하기 전에 탐과 핏이 먼저 시험한다. 핏이 클로이 역할이다.

왜 핏이 먼저 하나: 탐(클라우드)의 깃허브 도구는 저장소를 만들 권한이 없어 403이 났다(실측). 로컬의 gh로 핏이 만든다. [해결 경로: 우회]

핏이 할 일(로컬, 사람 확인이 필요 없는 것만):
1. `gh repo create hansunghee7/agent-chatroom --private` 로 **비공개** 저장소 생성.
2. 클론해서 main에 올린다: `tasks/assets/chatroom/chatroom-relay.yml` → `.github/workflows/chatroom-relay.yml`, `tasks/assets/chatroom/README.md` → `README.md` (solar-bible에서 복사).
3. 브랜치 `chat/001-hello`를 만들고 `tasks/assets/chatroom/소통문서-001.md` → `chat/001/소통문서.md`로 올린 뒤 PR `[교신 001] 탐↔핏 시험`을 연다.
4. PR 번호를 `mailbox/탐/`에 올리면 깃액션 봇이 탐에게 알린다. 탐이 저장소 접근(add_repo)을 붙이고 PR을 구독한다.
5. 이후는 소통문서의 규칙대로 진행: 핏은 1~2분 간격으로 PR 새 댓글을 확인(클로이와 같은 조건)하고 `[핏→탐 #n]` 형식으로 답한다. 확인 방법과 간격을 첫 답에 적는다.

주의: 시험 내용은 가짜 과제만. 실제 업무 자료, 키, 토큰을 올리지 않는다. Slack 중계는 2차 시험이며 `SLACK_WEBHOOK_URL`은 사장님이 만들어 저장소 비밀값에 넣는다(지금은 비워 둔다).
