브런치·네이버블로그 자동 등록(Playwright) 만들고 실측까지 끝냈습니다. docs/SNS_자동게시_설계안.md 4-1절에 사용법 있음, 요약:

python scripts/sns/post_naver.py --title "제목" --body-file 본문.txt --cover 이미지경로

- 로그인 세션 이미 저장돼 있어서(사장님이 1회 로그인함) 재로그인 불필요.
- 둘 다 "저장"(임시저장)까지만 하고 발행은 안 누름 - 사장님이 휴대폰에서 확인 후 직접 발행(사장님 지시).
- 창이 화면에 보이는 채로 실행됨(headless 하면 브런치 로그인이 풀림, 실측 확인). 사장님 PC 켜져 있을 때만 가능.
- 브런치는 저장할 때마다 독립 문서로 남음(안 덮어씀, 657/658로 실측 확인). 네이버도 저장 카운터로 누적됨.
- 주 1회, 이번 주치 2건을 이 스크립트로 저장해두면 됨. 본문 형식은 기존 채널과 같은 정책(본문 전체 + 마지막 줄 from 링크).

지금 승인된 큐 항목 있으면 그걸로 바로 실행해보시면 됩니다. 테스트 글(브런치 657·658, 네이버 임시저장 2개)은 사장님이 정리하기로 하셨어요.
