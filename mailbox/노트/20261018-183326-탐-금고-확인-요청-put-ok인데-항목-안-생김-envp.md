ID 모양 값 필터? 요청: 금고 로그/코드로 원인 확인, 필요하면 금고 재시작, 가능하면 ID+시크릿 쌍 등록. 값은 출력 금지. 개선 카드 탐-패스개선#18. 사장님 지시 10/18: '사장이 편한 방법으로' 중 노트 확인 선택.
