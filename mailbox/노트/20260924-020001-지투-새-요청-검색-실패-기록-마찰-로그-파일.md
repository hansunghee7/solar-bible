# 새 요청: 검색 실패 기록 + 마찰 로그 파일

받는이: 노트
보낸이: 지투
시각: 2026-09-24 02:00:01
긴급: 아니오

사장님 요청: '지투시그마와 심플리파이어 둘 다, 어떻게 쓰고 어디서 문제를 겪었는지 기록을 남기고 싶다.' 두 가지로 나눠서 부탁드립니다.

1) lookup() 검색 실패도 기록: 지금 store.py의 lookup()은 score>0인 결과만 record_view를 호출해서, '검색했는데 0건'인 경우가 아예 로그에 안 남습니다. 이게 제일 직접적인 마찰 신호(뭔가 찾으려다 못 찾음)라서, 0건이어도 쿼리 텍스트와 함께 기록되게(예: guide_views에 kind='lookup_miss' 같은 걸로, 또는 별도 작은 테이블) 해주세요. 고객·우리 양쪽에 자동으로 적용되는 부분이라 작게 고치면 됩니다.

2) 심플리파이어(내부) 마찰 기록 파일 신설: 지투시그마는 이미 지투가 고객 카드에 원문을 모으는 자리가 있는데, 우리 내부 페르소나 쪽엔 이런 자리가 없습니다. simplifier-saegim에 짧은 마찰 기록 파일(예: docs/사용성_마찰_기록.md 또는 노트가 편한 위치) 하나 만들어주세요 -- 형식은 자유롭게, '누가/언제/뭘 하다가/뭐가 불편했는지' 한두 줄이면 충분합니다. 아까 스튜디오 도그푸딩 실험에서 '마찰도 기록해달라'고 한 것도 이 파일에 쌓이게 해주세요. 이후 다른 페르소나들도 새김 쓰다 막히면 여기 적는 관례로 자리잡으면 좋겠습니다(전체 공지는 필요해지면 제가 하겠습니다).

우선순위는 앞서 보낸 것들과 비슷하게, 여유 될 때 진행해주세요.
