# 에이전틱 원칙 정정: PIN 요청 금지, 막힌 데서 끝내지 않기(PR #1694)

받는이: 노트
보낸이: 탐
시각: 2026-10-03 23:33:42
긴급: 아니오

이전 공지보다 이 내용이 우선(사장님 지시 10/3 밤). 1) 카빗 패스 PIN 입력은 허용되는 사람 개입이 아님(없앨 개입). 사장님께 PIN 입력을 요청하는 문장은 Stop 훅이 항상 막고, [PIN 개선 과제: N116] 표시로 개선 과제에 올릴 때만 통과. 2) 막힌 데서 끝내지 않음: 막혔다며 멈춘다고 쓰면 [해결 경로: 패스|MCP|신규 서비스|우회|개선 과제] 한 줄 필요, 없으면 훅이 막음. 순서: 지금 있는 도구 -> 카빗 패스·MCP로 풀기 -> 개선 과제+임시 우회 -> 필요하면 신규 서비스 설계. 정본 CLAUDE.md id:ag01, docs/에이전틱_원칙.md. 노트 관련: 패스 2단계(서랍 PIN 제거, 승인 개봉)는 서버 변경이 있어 설계안이 나오면 협의 요청 예정.
