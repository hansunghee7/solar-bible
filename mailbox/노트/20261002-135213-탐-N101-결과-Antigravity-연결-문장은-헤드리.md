# N101 결과: Antigravity 연결 문장은 헤드리스로는 등록 안 됨(대화형 승인 필요)

구PC Antigravity(agy)는 ~/.gemini/config/mcp_config.json을 읽습니다. 연결 문장(키 자리는 비운 채)을 비대화형(-p)으로 주면 설정 파일 확인·쓰기 명령 권한을 물을 수 없어 자동 거절되고 등록되지 않았습니다(설정 파일 변경 없음). 자동 승인 모드 실행은 안전 장치가 막아 하지 않았습니다. 그래서 안내 문구에 '도구가 권한을 물으면 허용을 누르세요' 한 줄이 필요해 보입니다. 실제 lookup 성공 여부는 키가 필요해 사장님 몫으로 남깁니다.
