[지투 지시 V1, 사장님 지시 9/25] 가이드 버전 관리

사장님: 가이드의 버전을 따고, 지투가 개선한 새 버전을 만들어 MCP에 적용. 과거 버전은 남아 있어야 함. 향후 고객 대시보드에 사용현황 옆 '버전 기록' 메뉴 필요.

스펙:
1. 버전 단위 = (회사, 문서). 예: simplifier/UX_GUIDE v1, ztosigma/UX_GUIDE v1.
2. 재시딩할 때 기존 행을 덮지 말고 새 버전으로 저장. 버전마다: 번호, 생성 시각, 원본 해시(git 커밋 또는 URL+해시), 만든 이, 변경 요약 한 줄, 승인자, 상태(초안/현재/보관).
3. MCP(lookup·list_sections·get_section)는 '현재' 버전만 읽는다. 되돌리기 = 현재 지정만 이전 버전으로 바꾸기(데이터 삭제 없음).
4. 절 id는 버전을 넘어 유지(같은 id 주석 = 같은 절). 조회·인용 이력은 절 id + 버전으로 기록해 '어느 버전을 보고 인용했는지' 남기기.
5. 지금 두 문서의 현재 상태를 v1로 박제(파싱 결함 있는 그대로가 v1). 파서 수정 뒤 재시딩한 것은 v2 초안으로 들어가고, '현재' 전환은:
   - simplifier/UX_GUIDE: 지투가 전환해도 됨(우리 자산)
   - ztosigma/UX_GUIDE: 사장님 승인 뒤에만. 승인 전에는 v2 초안으로만 존재.
6. 데이터층에 버전 목록 조회(고객 자기 회사만, usage와 같은 경계) 도구 또는 usage 응답 필드. 화면(버전 기록 메뉴)은 향후라 지금은 데이터만.
7. 변경기록 문서: simplifier-saegim/docs/새김_변경기록.md (지투가 방금 만듦, 곧 PR). 가이드 버전 표에 행 추가하는 것까지가 완료.

순서: N10 파서 수정과 겹치니 V1(버전 저장)을 먼저 넣고 그 위에서 파서 수정본을 v2로 심는 게 맞다고 봅니다. 순서 판단이 다르면 이유 한 줄로 알려 주세요.
