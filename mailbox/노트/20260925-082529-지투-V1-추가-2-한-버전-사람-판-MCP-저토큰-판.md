[지투 지시 V1 추가 2, 사장님 지시 9/25] 한 버전 = 문서 두 형태(사람 판 + MCP 판)

사장님: UX 가이드는 이원화. 사람이 읽기 좋은 판과, MCP가 끌어가서 작동하기 좋고 토큰 소모가 적은 판. 한 버전에 두 문서 형태가 나온다.

스펙:
1. 원본은 버전당 하나(두 문서를 따로 쓰지 않음, 어긋남 방지). 재시딩 때 한 원본에서 두 판을 같이 만들고 같은 버전 번호를 붙인다.
2. MCP 판(lookup·list_sections·get_section이 주는 것): 규칙·적용·값·찾는 말 줄만. 사례·경위·버전 머리글은 뺀다. 찾는 말은 검색 점수에는 쓰되 응답 본문에서는 빼도 됨(판단은 노트).
3. 사람 판: 전부(사례, 버전 머리글 '이전 대비 개선 사항', 목차) 렌더링한 HTML. guide_link가 이 판을 연다. 비공개 경로(대시보드와 같은 인증)여야 함, 공개 사이트 아님.
4. 절 모양은 UX_GUIDE 6.1(PR #143, id 202e): '규칙: / 적용: / 값: / 찾는 말: / 사례:'. 이 줄 머리로 잘라 MCP 판을 만든다. 6.1 모양이 아닌 옛 절은 지금처럼 본문 전체를 MCP 판에 넣고, 목록에서 '미변환'으로 표시(지투가 차례로 옮김).
5. 사례를 MCP에서 꼭 봐야 할 때는 get_section(..., detail=true) 같은 선택 인자로만.
6. 실측 보고: 같은 절(1.13, 1.14, 1.12)의 MCP 판 글자 수 전후, lookup 같은 질의 응답 총 글자 수 전후.
V1(버전 저장)·N10(파서) 위에 얹는 것이라 순서는 V1 → N10 → 이것. 고객 가이드는 이 이원화도 적용 전 사장님 승인(개선 방향 문서에 G9로 올려 둠).
