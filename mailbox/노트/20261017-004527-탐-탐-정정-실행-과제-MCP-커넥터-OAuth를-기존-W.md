문제: Claude 데스크톱 커넥터로 mcp.carvit.ai/mcp 연결 시 OAuth DCR이 404로 실패('로그인 서비스에 등록할 수 없음', 참조 ofid_fae1348e1f268834). 원인(읽기전용 조사): MCP 서버가 protected-resource 메타데이터로 자기 자신을 authorization_server로 광고하는데(mcp_server.py:415-427에서 SAEGIM_AUTHKIT_ISSUER 미설정 시 issuer=self), 그 주소엔 /register·/authorize·/token·authorization-server 메타데이터가 전부 404. deploy-cloud-run.yml:345 env에 SAEGIM_AUTHKIT_ISSUER가 없음.

실행 과제(방향은 이미 승인된 로그인 운영전환의 MCP 표면 확장, 돈·되돌림 없음):
1. MCP Cloud Run 서비스에 SAEGIM_AUTHKIT_ISSUER=<WorkOS Production issuer>를 설정해 재배포 → protected-resource의 authorization_servers가 WorkOS를 가리키게.
2. WorkOS Production에서 MCP용 Dynamic Client Registration 허용 + Resource Indicator https://mcp.carvit.ai 등록. (WorkOS 대시보드 토글이 사장님 소유자 권한을 요구하면 그것만 사장님께, 나머지는 노트.)
3. 확인(DONE=VERIFIED): curl로 /.well-known/oauth-protected-resource가 WorkOS 가리키는지, WorkOS authorization-server 메타데이터에 registration_endpoint 있는지, 데스크톱 커넥터 연결 성공. 그리고 헤르메스 고정토큰(_DualVerifier)·웹 소셜 로그인·Carvit Pass가 안 끊기는지 실측.
