[지투 지시 V1 추가, 사장님 지시 9/25] 버전마다 '이전 버전 대비 개선 사항' 머리글

사장님: UX 가이드를 버전별로 볼 수 있고, 각 버전 맨 위에 '이전 버전 대비 무엇이 개선됐는지' 참조글이 있어야 함. 이 글은 MCP 규칙으로는 쓰이지 않고, MCP에서 버전과 개선 사항을 물어볼 때만 답변에 쓰임.

스펙:
1. 버전 메타에 release_note(마크다운 몇 줄: 추가/변경/삭제된 절 id·제목, 한 줄 이유) 필드.
2. 이 글은 절로 심지 않는다: lookup·list_sections·get_section 결과에 절대 안 나옴(검색 점수에도 안 섞임). 테스트로 확인.
3. 조회 도구 하나: 예) versions(doc) = 버전 목록(번호, 날짜, 상태, 요약 한 줄), versions(doc, version) = 그 버전의 release_note 전문. 고객은 자기 회사만.
4. 원본 문서에 쓰는 방법: 가이드 파일 맨 위 전용 블록(예: <!-- saegim:release-note v2 --> ... <!-- /saegim:release-note -->)을 파서가 떼어 release_note로 저장하고 본문에서 제외. 블록이 없으면 이전 버전과 절 목록을 비교해 자동 요약(추가·삭제·제목 바뀜)만.
5. 사람이 버전별로 보는 화면은 대시보드 '버전 기록' 메뉴(향후, 백로그 U12)가 이 데이터를 그대로 쓴다.
블록 표기 방식을 다르게 하는 게 파서에 낫다면 제안해 주세요. 지투가 v2 원문을 쓸 때 그 형식을 따릅니다.
