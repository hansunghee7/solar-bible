## 로컬탐 몫 (클탐이 직접 못 하는 것)
- 구PC 헤르메스: 모델 연결, 점검 질문 실행, 덱스 검증 마무리.
- 하이쿠 API 시험(타미 두뇌 교체와 E1 재실행 포함): 로컬탐 소유. API 활용 PM은 사장님이 로컬탐과 클탐 의견을 들은 뒤 결정한다.
- 지원사업 후보 리서치: PR #2 `[탐→로컬탐 #14]`로 발주(스크립트 실행, 도구 호출 5회 이내). 결과 파일 경로를 댓글로 올리면 클탐이 출처 표본 대조.
- 감시 경고 3건 원인 확인(Fetch SNS public, Fetch Naver content, 새김 세션 유휴 점검). 로컬 상태판만 볼 수 있다.
- 고아 키 정리와 금고 보관 순서 수정은 사장님이 정한 대로 로컬 크레딧 회복 뒤(보류). 트렐로 카드 평문 키 삭제는 크레딧 대조 뒤.
- 구PC 크론, 타미 실행, `엔진:` 표시 한 주 시험(탐 업무대장)의 집계 재료.
- 지투시그마 대표용 시연(N172) 리허설과 시연: 로컬탐이 한다(사장님 결정).

## 클탐 몫
- 판정과 기록, 사장님 소통, 외부 발신 문구 초안(발신은 사장님 승인).
- 외부 교신용 저장소 `hansunghee7/chatroom-zitu` 연결과 매뉴얼 이전, 클로이 첫 교신 시험. 클탐 크레딧이 줄어 로컬탐이 이어받을 수 있으며 그때는 위 인수인계 문서 4번 순서를 따른다.
- 클탐은 로컬 일감에 지시하지 않고 판정 의견만 낸다. 승인과 지시는 로컬탐 채팅에 사장님이 직접 입력한 것만 효력이 있다.

## 사장님 결정 대기
- 외부 공개 관문 기준, PIN 최초 설정 시점, 평문 키 삭제 시점, 클탐 정기 업무 제외 기록 여부, 첫 입증 대상(Builders 전후 비교), N172 시연 대상이 지투시그마 손 대표님과 같은지.

## 주의
- 내부 저장소 `agent-chatroom`에는 외부인을 초대하지 않는다(내부 논의가 모두 보임). 외부 교신은 `chatroom-zitu`만 쓴다.
- 클라우드 크레딧이 약 29달러 남았으니(11/5 만료) 클탐은 판정과 기록 위주로만 쓴다.
