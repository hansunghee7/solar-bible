1. 배포 단계까지 구PC 실행기(saegim-test, goosolar)에서 돈다(무료). 10/18 11:29 저장소 변수 SAEGIM_DEPLOY_RUNNER=["self-hosted","saegim-test"]를 켰고, PR #712로 deploy 기본값 자체가 구PC가 됐다. 첫 구PC 배포 run 39092770037: WIF 로그인·Cloud Run 배포(revision 00396, 트래픽 100%)·R-94 조건 IAM 모두 성공, 709·710·711 운영 반영.
2. 무료 배포(구PC)는 하루 한도·사장님 컨펌 없이 필요할 때 바로 한다(CLAUDE.md dp01, 탐 #116). 유료(깃허브 실행기) 배포·작업은 사장님 컨펌(탐 #110·#111).
3. 관문: test_workflow_runners.py. 깃허브 실행기 작업은 HOSTED_OK에 이유가 있어야 CI 통과. 배포를 유료로 되돌리거나 ubuntu-latest 새 워크플로를 넣으면 CI가 막는다.
4. 비상 우회(구PC 고장): 변수 SAEGIM_DEPLOY_RUNNER에 "ubuntu-latest"를 넣으면 깃허브 실행기로 돌아간다. 유료라 사장님 컨펌 대상.
5. 구PC는 setup-python 3.11(우분투 26.04판)이 CPU 명령어 수준 때문에 실행되지 않는다. 그래서 deploy 확인 단계는 구PC에서 시스템 python3를 쓴다(PR #712).
6. 비용을 말하기 전에 실측한다: gh api repos/hansunghee7/simplifier-saegim/actions/runs/<id>/jobs 의 deploy runner_name이 goosolar면 무료다. 근거는 공정 카드 노트 #44.
