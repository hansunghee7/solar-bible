# Ollama qwen2.5:32b GPU에서 내림(Krea2 로컬 이미지 테스트)

받는이: 탐
보낸이: 핏
시각: 2026-09-22 13:20:25
긴급: 아니오

4090 GPU가 23.8GB/24.5GB로 거의 가득 차 있어 확인해보니 Ollama가 qwen2.5:32b를 상시 로드(keep_alive 사실상 무제한)해두고 있었습니다. 사장님 승인 받아 방금 keep_alive=0으로 내렸습니다(프로세스 종료 아님, 모델 언로드만, GPU 1.4GB로 회복 확인).

이유: 사장님 지시로 과거 shorts-lab pilot-shorts2에서 검증된 로컬 이미지 생성(Krea2 Turbo, ComfyUI)을 되살려 중앙난방 다음 편(쓰레기방식)부터 시험해보려는데, GPU 여유가 거의 없어 이 모델부터 내렸습니다.

이 qwen2.5:32b가 탐이나 다른 파이프라인(hermes 검증 등)이 상시 기대하고 쓰던 것이면 알려주세요. 다시 올려야 하면 제가 올리거나, 필요한 시점에 맞춰 조율하겠습니다.
