[핏→탐] 카빗 업스케일 사용성 테스트 결과 (키워드: 업스케일)

결론: 결과 품질은 Video2X와 사실상 같고 4090에서는 1초 안팎으로 빠르다. 다만 GPU를 자동으로 못 고르는 환경이 있어 첫 사용에서 막힌다.

시험 입력: lf01 실제 컷 프레임. 360p(640x360) x3, 512p(960x512) x2, 추가로 720p x2·x4, 1080p x2. 기준은 같은 프레임을 video2x.exe(realesrgan animevideov3, -d 1=4090)로 올린 결과. 웹은 아티팩트 HTML을 로컬 주소로 띄워 별도 크롬(headless)에서 실행.

1) video2x 결과와 같은가 [실측]
- 360p x3(1920x1080): PSNR 55.73dB, 평균오차 0.10/255, 차이>10 화소 0.019%(최대차 66은 맨 아랫줄 가장자리).
- 512p x2(1920x1024): PSNR 59.09dB, 평균오차 0.06, 차이>10 화소 0.003%.
- 눈으로 확대 비교(가장자리·벽·문틀)에서 구분 안 됨. 단순 쌍삼차 확대는 PSNR 33~39dB로 뚜렷이 흐림. 4090과 AMD 내장 그래픽 결과는 최대 1 단계 차이뿐.
- 글자(DELIVERY)가 든 컷은 이 입력에서 별도 확대 대조는 못 했다(다음 시험).

2) 속도 [실측]
- 4090: 360p x3 0.75초, 512p x2 0.67초, 720p x2 1.1초(2560x1440), 1080p x2 2.2초(3840x2160), 720p x4 1.4초(5120x2880).
- AMD 내장 그래픽(RDNA-2)으로 돌면: 360p x3 36.7초, 512p x2 75초. 약 50~110배 느림.
- 중요: 페이지는 requestAdapter({powerPreference:'high-performance'})를 부르지만, 이 PC에서는 크롬이 AMD 내장을 골랐다. 4090이 잡히는 건 크롬 옵션 --force_high_performance_gpu를 줬을 때뿐(--use-webgpu-power-preference 등은 효과 없음). 화면 로그에 'amd'/'nvidia'가 떠서 알아볼 수는 있다.
- 사장님이 평소 쓰는 크롬(Claude in Chrome 연결분)은 WebGL 렌더러가 'Microsoft Basic Render Driver'(소프트웨어)이고 WebGPU 어댑터가 null이라 '실패: GPU를 찾지 못했습니다'가 떴다. 이 크롬에서는 아예 못 쓴다(하드웨어 가속이 꺼졌거나 원격 세션 상태 [추정], chrome://gpu는 자동화로 못 열어 확인 못 함).

3) 쓰기 편한가
- 되는 것: 사진 올리기, 배율 선택, 키우기, PNG 저장(파일명 in720_x2.png로 정상 다운로드, 5MB), 맞춤/100% 전환. 영상 파일을 주면 '이미지 파일이 아닙니다'로 막고 키우기 버튼이 잠긴다.
- 불편 1: 실패 안내가 '실패: GPU를 찾지 못했습니다' 한 줄뿐. 어떻게 하라는 안내가 없다(예: 크롬 설정 '가능한 경우 하드웨어 가속 사용' 켜기, 크롬/엣지 최신 확인).
- 불편 2: 원본과 결과가 같은 크기로 나란히 맞춤 표시라 차이가 안 보인다. 확대 시 두 쪽이 같이 움직이거나 앞뒤 슬라이더가 있으면 비교가 쉬울 것.
- 불편 3: 배율이 x2/x3/x4 고정이다. 우리는 360p x3 후 1080p, 720p x2 후 1080p로 쓰는데, 720p x2는 2560x1440이 나와 1080p로 줄이는 단계가 따로 필요하다. '출력 폭 1920으로 맞춤' 옵션이 있으면 video2x 현재 방식과 같아진다.
- 불편 4: 한 번에 한 장이다. 컷 수십 장은 못 올린다(프레임 캡처 후 배치 처리가 필요하면 별도 과제).
- 오류: 콘솔 오류는 favicon 404 하나뿐(로컬 서버 탓).

4) 한계
- 합성 그림 아닌 실제 컷 2종(360p·512p)에서만 대조. 글자가 많은 컷, 인물 얼굴 컷은 아직 안 봤다.
- 사장님 크롬에서 4090으로 도는 것은 확인 못 했다(위 2번).
- 영상 자체는 못 받는다. 쓰려면 프레임 추출→웹→재조립 또는 video2x가 계속 담당.

제안(탐이 정함): (가) GPU 실패 안내문 보강, (나) 출력 폭 맞춤 옵션, (다) 앞뒤 비교 확대. 파일: C:/work/_ops/v2x_rea/ut/ (in*.png 입력, ref*.png video2x 결과, web*.png 웹 결과, cmp360_text.png 눈 비교, run_web.py·run_use.py 재현 스크립트).
