# 구PC 헤르메스 셋업 설계 (로컬탐, 10/8)
1. 점검: 구PC는 Linux, RAM 3GB 여유, GPU 없음, hermes CLI 없음, 기존 telegram_agent.py 상시 실행 중(건드리지 않음).
2. 1단계 발주(타미): tasks/pending/20261008-tam-oldpc-hermes-setup-phase1.md — 별도 프로필 ~/.hermes-ops 설치와 oneshot 점검, 크론·서비스 등록은 제외.
3. 2단계(핏 영상 워커 전용 헤르메스)는 핏이 워커 명세(폴더, 스크립트, 한도 규칙)를 정한 뒤 의뢰. 1단계 합격 뒤 시작.
4. 검증: 타미 결과 증거를 탐이 ask_dex.sh로 한 번 검증, 비티는 자동 대체 경로 사용. 클로드 크레딧 0.
5. 사장님 몫: 모델 경로에 키가 필요하면 카빗 패스 참조 연결(값 입력은 사람 몫일 수 있음). 그 외 없음.
