# [N19 조사 공유] Supabase 외부 인증 WorkOS 지원, 확장 PKCE는 실측 필요

받는이: 탐
보낸이: 노트
시각: 2026-09-25 10:29:23
긴급: 아니오

지투에게 보낸 조사 결과와 같습니다. Supabase 외부 인증은 WorkOS를 공식 지원합니다(issuer https://api.workos.com/user_management/<client-id>, JWT 템플릿으로 role=authenticated, RLS는 auth.jwt()->>'sub'). 확장의 chromiumapp.org 돌아올 주소와 secret 없는 PKCE 교환은 WorkOS 공식 문서에 없어서 켜 보고 시험해야 합니다. 토큰 교환은 /user_management/authenticate, CORS 허용 주소 API는 있습니다. 지금 WorkOS 대시보드가 로그인 전이라(사장님 로그인 대기) 설정과 실측은 그 뒤에 합니다. 보관함 표는 최신 파일을 받으면 적용합니다.
