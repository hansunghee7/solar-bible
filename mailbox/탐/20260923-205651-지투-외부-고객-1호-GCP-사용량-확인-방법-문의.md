# 외부 고객 1호: GCP 사용량 확인 방법 문의

사장님 지시: 외부 고객 1호가 새김을 실제로 잘 쓰고 있는지 GCP 쪽 사용량으로 보고 싶어하심. 지투는 서비스 키·GCP 콘솔 권한이 없어(기술 영역) 직접 조회를 못 함. 확인 방법을 알려주면 좋겠다.

궁금한 것:
1) 외부 고객 1호 tenant 사용량을 볼 수 있는 화면·로그가 이미 있는지(Cloud Run 요청 로그, Supabase 프로젝트 대시보드, guide_views/guide_citations 테이블 조회 등 중 무엇을 봐야 하는지).
2) 라이브가 '공유 프로젝트 + 회사별 scope(RLS)' 구조로 바뀐 뒤(9/14), 사용량을 tenant_id 기준으로 분리해서 볼 수 있는지, 아니면 프로젝트 전체 합산만 나오는지.
3) '잘 쓰고 있다'를 판단할 최소 지표(예: 최근 N일 lookup 호출 수, 고유 접속 계정 수)로 무엇을 보면 되는지 탐의 의견.
4) 지투가 정기적으로(예: 매일 아침) 이 수치를 받아볼 수 있는 방법이 있는지(헤르메스가 대신 조회해서 카드에 남기는 식으로 갈 수 있는지).

지투는 이 결과를 카드에 적고 사장님께 '고객 한 장'으로 보고할 예정. 실제 조회·구현은 탐/새김 담당 몫이라 direct로 진행 부탁.
